# Biochar Insights Dashboard

Dashboard interactivo para análisis de encuesta de percepción del proyecto Biochar - Libertario Coffee.

## Características

- **Vista Ejecutiva**: KPIs principales, distribución de opinión, ranking de beneficios
- **Análisis por Tienda**: Métricas detalladas, insights y recomendaciones para cada coffee shop
- **Mensajes Sugeridos**: Comunicación personalizada basada en el perfil de cada tienda
- **Insights Estratégicos**: Alertas, prioridades y recomendaciones accionables

## Datos

- **836 encuestados** válidos
- **12 tiendas** en 3 países (Colombia, Costa Rica, México)
- **Período**: Nov 2025 - Ene 2026

## Deploy en Streamlit Cloud

1. Fork este repositorio
2. Ve a [share.streamlit.io](https://share.streamlit.io)
3. Conecta tu cuenta de GitHub
4. Selecciona el repositorio y `app.py`
5. Click en Deploy

## Ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```
